# Benchmarks

<!-- gen:benchmark-table -->

Each benchmark has the same three pages:

| Page | Contents |
| --- | --- |
| **Tasks** | Every task as a row with its demo playable in place — the landing page |
| **Triage board** | Keep/drop decisions and what is still open |
| **Capability coverage** | What the suite exercises, and the thin spots |

Adding another benchmark is a YAML file plus task pages; every view picks it
up automatically. See [Adding a benchmark](../contributing/adding-a-benchmark.md).
