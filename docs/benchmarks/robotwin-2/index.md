# RoboTwin 2.0 tasks

Fifty bimanual tabletop tasks on a dual-arm ALOHA-AgileX, each one Python class with a scene
builder, a success predicate and a scripted expert. Every row plays **our recording of that
expert** on an uncommon seed as a six-camera grid (world, observer, head, front, left wrist,
right wrist); the official ALOHA head-camera clip is linked from the task page. Two rows have
no clip because the expert itself cannot complete them on any seed we tried.
